# Role
你是一位精通網頁前端開發（HTML/CSS/JavaScript）的「資安風險評估專家與資深架構師」。

# Task
請依據我提供的情境演練資料，製作一個「單一檔案（Single-file）」的「企業資安風險評估、識別與防禦總結儀表板」HTML 網頁。
這個網頁**不需要任何測驗或答題功能**，而是要將資料轉化為可互動的、視覺化的專家風險評估報告，供管理階層與工程團隊進行資安盤點、風險識別與防禦部署。

# UI/UX & Design Requirements
1. **單一檔案架構**：所有的 HTML、CSS 和 JavaScript 必須全部寫在同一個 `.html` 檔案中，不引用外部本地檔案，以確保離線可用。
2. **資安戰情室視覺（Dark Mode）**：
   - 採用高級感深色主題。
   - 主色調：深藍底色 (#0F172A)、邊框 (#22314D)、科技藍 (#2563EB)。
   - 分類視覺：
     * TCP Port No. 識別：網頁藍/青色 (#06B6D4)
     * 資安威脅：警告紅/橘色 (#EF4444)
     * 系統安全開發 (SSDLC)：安全綠色 (#10B981)
     * 資安管控模式：紫色 (#8B5CF6)
3. **響應式與現代化排版**：採用側邊欄（Sidebar）或分頁（Tabs）切換機制，讓使用者能流暢地在「風險總結面板」與「四大核心領域」之間切換。避免超過 150 字的冗長不開口散文，多使用卡片、表格與 bold-lead（粗體帶頭）的清單。

# core functional Modules (不可省略)
1. **Module 1：C-Level 專家風險識別與防禦總結（總覽頁面）**
   - **威脅統計卡片**：呈現總盤點情境數（27項）、涵蓋的核心領域、以及涉及的網路關鍵 Port 數量。
   - **高階管理總結（Executive Summary）**：針對「通訊埠曝露、人為漏洞/社交工程、開發階段安全(SSDLC)缺失、策略與技術面脫鉤」四大核心痛點，給出宏觀的專家防禦建議。
   - **縱深防禦地圖**：用一個美觀的純 CSS/HTML 區塊（例如堆疊層級圖），展示從「策略面 -> 管理面 -> 技術面 -> 系統開發(SSDLC)」的縱深防禦防護罩概念。

2. **Module 2：核心領域互動式風險盤點表（分頁切換）**
   - 點選四大領域（TCP Port/資安威脅/SSDLC/資安管控）時，下方動態切換顯示該類別的所有情境卡片或表格。
   - **情境卡片 (Scenario Card) 內文必須包含**：
     * **核心實體標籤**：子項目名稱、對應技術/Port、教材頁碼。
     * **風險情境案例敘述**：將原本的敘述凸顯（如使用引言區塊或深色背景框）。
     * **關鍵字閃爍/標籤**：以 Tag 形式精緻呈現 (e.g. #明文傳輸, #Port21)。
     * **專家評估防禦實踐**：以**強烈對比的亮色（如安全綠或科技藍）**，條列出具體實踐與說明。

3. **Module 3：關鍵字（Keywords）雲端快速檢索過濾**
   - 網頁頂端或側邊提供一個簡單的關鍵字搜尋框或熱門關鍵字標籤（如：MFA、加密傳輸、DDoS、網路釣魚），點擊時能即時篩選出對應的風險情境案例。

# Output Format
請不要包含任何多餘的解釋、前言或 meta-commentary。請直接輸出完整的 `<!DOCTYPE html>...</html>` 程式碼，確保程式碼標籤閉合完美、CSS 樣式完備。
